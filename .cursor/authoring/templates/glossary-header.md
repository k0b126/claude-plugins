# {Repo} — shared language

The vocabulary this repo's people and agents use to talk about its work. A
term whose full definition has an authoritative home elsewhere gets one line
here plus the pointer.

Terms carry a **_Provenance_** line saying where the word came from —
`borrowed` (and from which field), `narrowed` (borrowed, with the restriction
stated), or `coined` (no counterpart exists). The rule it enforces: **borrow a
word and its definition, or coin a new one — never borrow a word and redefine
it.** A borrowed word carrying a local meaning is worse than an invented one,
because the reader applies the textbook meaning and is silently wrong.

A borrowed term is also a **guardrail**: this file is loaded into sessions, so
the word chosen decides which body of prior knowledge a reader — model
included — reasons with. Where a term comes from a field this repo only partly
follows, the entry names the **_Tradition_** it belongs to and
**_Where we depart_** from it — at the **altitude of the tradition named**: if
the tradition is a way of thinking, a missing component is not a departure.

**Concretize when the concrete thing is constitutive; generalize when it is
merely current.** The test: *what would make this untrue?* Constitutive
structure goes in the body; merely-current structure goes under
**_Realization_**, where it can be edited without re-deciding the term.

Markers fall into four classes — **identity** (the body), **boundary**
(`_Avoid_`, `_Collision_`), **ancestry** (`_Provenance_`, `_Tradition_`,
`_Where we depart_`, `_Not a departure_`), **embodiment** (`_Realization_`).
**Every marker is optional, permanently** — written when an argument produces
it, never to complete a row.
